# Как вносить изменения

1. Возьмите задачу на [доске](<ССЫЛКА_НА_ДОСКУ>), назначьте себя, переведите в **In progress**.
2. Создайте ветку от свежего `main`:
   ```bash
   git checkout main && git pull
   git checkout -b docs/P2.1-architecture
   ```
3. Коммиты — маленькие и осмысленные, в повелительном наклонении:
   ```
   P2.1: добавить схему потоков данных
   P2.9: отрисовка рёбер между ветками
   ```
4. Откройте PR в `main`. В описании — `Closes #<номер issue>`, заполните шаблон.
5. Ревьюер — другой участник команды. Автор не мёржит свой PR без аппрува.
6. После мёржа ветка удаляется автоматически, карточка переезжает в **Done**.

## Что не попадает в репозиторий

- `.env` и любые ключи: `GITHUB_CLIENT_SECRET`, `SESSION_SECRET`, токены. В репозитории только `.env.example` с пустыми значениями.
- `node_modules/`, `dist/`, `coverage/`, клонированные для анализа репозитории.
- Личные настройки IDE.

## Definition of Done для любого PR

- [ ] Выполнены все пункты DoD из issue
- [ ] Документ или код связан ссылкой из README, если это новый раздел
- [ ] С G3: линтеры и тесты зелёные, покрытие не упало ниже 80%
- [ ] Получен аппрув
